# ☀️ Áurea Energia Sustentável

**Projeto Prático 1 — Programação Web Front-End**

Aplicação web desenvolvida para a disciplina **EC47C — Programação Web Front-End**, no período letivo de 2026/02, da Universidade Tecnológica Federal do Paraná (UTFPR).

O projeto apresenta a Áurea Energia Sustentável, uma empresa fictícia voltada à apresentação de soluções de energia solar.

---

## 🌱 Sobre o projeto

A Áurea foi idealizada com o propósito de apresentar alternativas de energia solar para residências, empresas e propriedades rurais, incentivando o conhecimento sobre fontes de energia mais sustentáveis.

O projeto está relacionado à **ODS 7 — Energia Limpa e Acessível**, que busca ampliar o acesso à energia confiável, sustentável, moderna e acessível.

### Objetivos

- Aplicar os conhecimentos de HTML5 e CSS3.
- Desenvolver páginas web com uma estrutura organizada e semântica.
- Criar uma interface visual consistente e responsiva.
- Apresentar uma proposta de serviço relacionada à sustentabilidade.

---

## 🖥️ Páginas desenvolvidas

### Página de login

Página inicial do site, com campos de e-mail e senha e navegação para o cadastro.

### Página de cadastro

Formulário com cinco campos: nome, idade, e-mail, senha e confirmação de senha.

### Página principal

Apresenta a empresa, suas propostas e soluções de energia solar, com menu de navegação, imagens, ícones, cartões informativos e links para os currículos dos integrantes.

> **Observação:** esta etapa é um protótipo estático de Front-End. Os formulários demonstram a estrutura e a navegação entre páginas, sem autenticação real ou armazenamento de cadastros.

---

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** layout, cores, tipografia e responsividade.
- **Google Fonts:** fontes Inter, Montserrat e Space Grotesk.
- **SVG:** ícones utilizados na interface.
- **GitHub Pages:** publicação do site.

O Projeto 1 concentra-se em HTML e CSS, sem utilização de frameworks.

## 📂 Estrutura do projeto

```text
frontend-universidade-2/
├── assets/
│   └── imagens e ícones SVG
├── login/
│   ├── cadastro.html
│   ├── login.css
│   └── login.js
├── main/
│   ├── main.html
│   ├── main.css
│   └── main.js
├── shared/
│   └── base.css
├── index.html
└── README.md
```

### Organização dos arquivos

- `index.html`: página de login.
- `login/cadastro.html`: página de cadastro.
- `login/login.css`: estilos das páginas de acesso.
- `main/main.html`: página principal da Áurea.
- `main/main.css`: estilos específicos da página principal.
- `shared/base.css`: estilos e variáveis compartilhados.
- `assets/`: imagens e ícones utilizados no site.
- `login.js` e `main.js`: arquivos mantidos para o desenvolvimento das funcionalidades previstas para a etapa seguinte.
